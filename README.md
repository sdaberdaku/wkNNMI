Tavazzi E., Daberdaku S., Vasta R., Calvo A., Chiò A., Di Camillo B. An adaptive Mutual Information-weighted k-NN algorithm for the imputation of static and dynamic mixed-type data.

Installation
The simplest way to install the package is by using devtools. After installing and loading devtools, just copy and paste the following rows to your R console.

`> url <- "https://gitlab.com/sysbiobig/wknnmi.git"`

`> devtools::install_git(url = url)`
